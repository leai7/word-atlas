# 詞光（個人改版）學習規則說明

> 這份文件記錄這個 fork（leai7/word-atlas）目前**所有學習與複習規則**。
> 之後要修改功能時，不論是自己看、找 Claude 還是其他 AI，先讀這份，就不用重新從程式碼摸清楚。
> 改了規則請同步更新這份文件。最後整理：2026-10-30。

---

## 0. 一句話總覽

1. 每天的**新詞** = 你指定的詞 + 系統補足差額，總數不超過每日上限。
2. 每天的**複習**：沒有造句的字出單字題；**有造句的字一律考造句**。
3. 每題只算**第一次作答**；答錯時複習間隔縮短，幾題後再練一次，並加入錯詞本。

---

## 1. 每日新詞

### 1.1 每日上限
- 預設每天 **10 個**，在「我的 → 學習設定 → 每日新詞」可改成 5／10／15／20／30。
- 開啟**考試計畫自動安排**時，上限改由考試計畫決定（見第 5 節）。

### 1.2 新詞從哪裡來（依優先順序）
1. **你指定的詞（待學清單）**：依加入順序，**算在每日上限內**。
2. **系統推薦**：名額不夠時，從「學習路線」中你的起點難度開始，挑還沒學過的詞補上。
   起點難度以上的詞都學完後，才會回頭從 A1 補。
3. 下列的詞不會被挑：已學過的、標為「認識」的、自訂單字（自訂單字只能靠指定）。

### 1.3 指定詞（待學清單）
- **加入方式**：
  - 單字頁的清單圖示，一次一個。
  - 今日頁「今天的新詞」區塊，貼上一串英文單字，用空格、逗號或換行分隔；詞庫裡沒有的會列出來，中文會被忽略。
  - 新增自訂單字時，勾選「加入今天的新詞」。
- **超過名額**：多出來的指定詞排到之後幾天，今日頁會列在「排到之後幾天」。
- **旅程進行中加入**：會換掉旅程裡**還沒見到**的系統推薦詞，總數不變。如果今天的名額都已經學過或見過，就排到之後。
- 學過的詞會自動移出清單。

### 1.4 認識的詞（跳過）
- 系統推薦的詞可以在兩個地方跳過，系統會補上下一個詞：
  - 今日頁：點詞旁邊的 ✓。
  - 「初次見面」卡片：點「早就會了，不用學」。
- 標為認識的詞**之後不會再被推薦**。考試計畫計算時，也把它當成已經會了。
- 想恢復可以在單字頁取消「已認識」。

### 1.5 新詞的學習順序
- **5 個一組**：先連續 5 張「初次見面」，再把這 5 個打亂順序考一輪。
- 最後一組只剩 1～2 個詞時，併入前一組，避免初見完馬上被考。
- 旅程中補進來的詞（指定、跳過後的補位、自訂單字），會和還沒見過的新詞**重新編組**，維持同樣的節奏。

## 2. 每日旅程的組成與順序

1. **單字複習**：沒有造句、而且已經到期的字，每趟最多 120 題。
2. **造句複習**：每趟最多 40 句，順序打亂。
3. **新詞**：依第 1.5 節分組。

其他規則：
- **同一個字一趟旅程只出現一次**，不論它是單字到期還是造句到期。
- 當天新學的字，不會再考它的造句。
- 沒做完的題目會留到下次。到期的複習會累積，但每題仍只出一次。
- 今日頁顯示「複習 N · 造句 N · 新詞 N」，以及預估分鐘數。
- 「只複習」按鈕會略過新詞，只做單字複習和造句複習。

## 3. 題型與評分

### 3.1 單字題型（沒有造句的字才會出）

| 題型 | 什麼時候出 | 內容 |
|---|---|---|
| 選意思 | 新詞、記憶還弱 | 看英文選中文，干擾項詞性相同 |
| 看圖補句 | 新詞、記憶還弱；要同時有插圖和例句 | 插畫加挖空的**日常例句**，選英文字 |
| 聽音辨詞 | 各階段 | 只聽發音選字 |
| 拼寫 | 記憶穩定後；可在設定關掉 | 看圖和中文拼字，可以一個字母一個字母地提示 |

- 題型由系統依熟悉度隨機挑選。
- 例句一律用每個字的第一句「**日常**」例句，**不會用雅思例句**。這是原作者的設計。

### 3.2 造句題（有造句的字一律出這題）
- **題目**：你的句子，把 chunk 挖空成底線，並提示搭配的中文；有填翻譯的話也會顯示。**不會顯示單字本身**。
- **作答**：打出挖空的部分。大小寫、彎引號和標點不影響對錯。
- 可以按「提示一個字母」，用了提示最多只能評為「困難」。
- **答完**：顯示完整搭配、單字和中文。可以按「換個句子」當場改寫，chunk 和複習時間都不變。
- 句子朗讀用裝置內建語音，裝置沒有英文語音時不會有聲音。

### 3.3 評分（單字題和造句題相同）
排程用 FSRS（ts-fsrs，FSRS-6），預設目標記憶率 90%，可在設定改成 85% 或 95%。

| 結果 | 評分 |
|---|---|
| 答錯 | 忘記（Again） |
| 答對，但用了提示 | 困難（Hard） |
| 答對，但太慢：拼寫或造句超過 20 秒，其他題型超過 9 秒 | 困難（Hard） |
| 答對，而且是拼寫或造句、6 秒內完成 | 簡單（Easy） |
| 其他答對 | 良好（Good） |

### 3.4 答錯
- 只有**第一次作答**會影響複習時間和正確率。
- 答錯評為「忘記」，複習間隔縮短，很快會再出現。
- 幾題後**當場再練一次**，最多 2 次，這幾次不算分：
  - 單字題會換一種題型，例如選意思答錯改看圖或聽音。
  - 造句題是同一句再考一次。
- 答錯的字會加入**錯詞本**（最多保留 300 個），可以在練習頁選「錯詞本」打字練習。

### 3.5 發音不熟
- 單字題和造句題答完後，回饋區都有「發音不熟」按鈕。
- 按下去會把這個字加入「**發音練習**」清單（第 7 節的跟讀模式）。
- 如果這題答對，而且原本評為「良好」或「簡單」，會**改評為「困難」**，讓下次複習提早；造句題會同時調整造句和單字的時間。
- 本來就是「困難」或答錯的題目，只加入清單，評分不變。同一題重複按不會重複扣。

### 3.6 「已掌握」的定義
已經進入複習階段，而且記憶穩定度 ≥ 21 天。

## 4. 造句（Chunks）

### 4.1 怎麼造句
- 在「初次見面」卡片或單字頁的「常用搭配」，點某個搭配下方的「造句」。
- 必填：英文句子。選填：中文翻譯。
- **只能用常用搭配來造句**，包括內建搭配和你新增的自訂搭配（第 4.4 節）。

### 4.2 挖空的部分
- 系統會自動找出句子裡對應這個搭配的那一段，可以手動修改。
- 比對方式：
  - 拼字開頭相同就算對上，所以 -s、-ed、-ing 都認得。
  - 內建約 160 個**不規則變化**對照表，例如 give/gave/given、take/took/taken，以及 child/children 這類名詞複數。
  - a、the、sth、sb、one's 這類填充字會被忽略。
- 找不到時欄位會是空白，要自己填。挖空的部分必須和句子裡的文字**完全一樣**。
- 挖空的部分沒有包含這個單字時會提醒你，因為複習時單字會直接出現在句子裡。
- 挖空幾乎是整句（5 個字以上，而且佔句子 70% 以上）時也會提醒，因為複習時等於默寫整句。

### 4.3 造句的複習排程
- 新造的句子**隔天早上**開始複習，之後由 FSRS 排程。
- 每句有自己的複習時間，單字也有自己的複習時間。**兩者任一到期**，就會出這個字的造句題（挑最早到期的那句）。
- **答造句題會同時更新**這句造句和這個單字的複習時間。
- **修改句子**（在單字頁編輯，或複習時按「換個句子」）**不會改變複習時間**。chunk 不能更換。
- 刪除造句，它的複習紀錄會一起刪除；單字本身的複習紀錄保留。

### 4.4 自訂搭配
- 單字頁或「初次見面」卡片的「常用搭配」最後，點「＋ 新增搭配」。英文必填、中文選填。
- 標示為「自訂」，用虛線框顯示，跟內建搭配一樣可以造句。
- 英文跟現有搭配相同時會被擋下，不分大小寫。
- 輸入看起來像句子（超過 6 個字，或含句號、逗號等標點）時，會提醒「這裡填詞組，造句請按造句」，確認後仍可新增。
- 刪除自訂搭配時，**用它寫的造句和複習時間會保留**。
- 不會修改原作者的詞庫，只存在你的學習資料裡。

## 5. 考試計畫

- 設定位置：「我的 → 學習設定」，填雅思考試日期和目標分數（5.5～8.5）。
- 目標分數對應的最高級別，依常見對應粗估：

  | 目標分數 | 學到的級別 |
  |---|---|
  | 5.0 以下 | B1 |
  | 5.5～6.5 | B2 |
  | 7.0～8.0 | C1 |
  | 8.5 | C2 |

- **每日新詞 =（從起點到目標級別、還沒學也沒標認識的詞數）÷（距離考試的天數 − 3）**，無條件進位。
  - 考前最後 3 天只複習，不排新詞。
  - 每天最多 60 個；超過時會提示你調高起點或調低目標。
  - 計算時會把今天已學的新詞加回去，所以學到一半數字不會一直變。
- 只有打開「按考試計畫自動安排每日新詞」才會套用；關閉時用手動設定的每日上限。
- 今日頁會顯示「距雅思考試還有 N 天」。

## 6. 自訂單字

- 位置：「我的 → 自訂單字 → 新增單字」，一次新增一個。
- 必填：英文單字、中文意思。選填：詞性、音標、例句（含中文）、常用搭配（每行一個，可以從字典直接貼上）、級別、話題、插圖。
- 詞庫裡已經有的字會被擋下，並提示你直接到單字頁加入待學。
- **跟內建單字的差別**：
  - 發音用裝置內建朗讀。
  - 不在學習路線和星圖裡，系統不會主動推薦，只能靠指定學習。
  - 要同時有插圖和例句，才會出看圖補句題。
- 插圖會縮到最長邊 1200px，存在這台裝置的瀏覽器（IndexedDB），匯出備份時一起帶走。
- 刪除自訂單字，會連同它的學習紀錄和造句一起刪除。
- 插圖的提示詞模板：`C:\Users\sandyhuang\Projects\詞光插畫提示詞_給ChatGPT.md`。這個檔案在公司電腦上，沒有放進 repo。

## 7. 打字練習（練習頁）

- **完全不影響複習排程**，只練拼寫和手感。
- 三種模式：

  | 模式 | 內容 |
  |---|---|
  | 單字 | 看圖和中文，拼出單字 |
  | 例句 | 看中文，默寫英文日常例句 |
  | 聽寫 | 只聽日常例句的錄音，寫下整句 |
  | 跟讀 | 練「發音練習」清單裡的字：聽錄音（可慢速、可聽例句）跟著唸，自己判斷「唸對了」就移出清單，「再練」就保留 |

- 預設**不顯示原文**，只用「·」表示有幾個字母；打錯的位置顯示你打的字，不洩漏答案。
- 「提示一個字母」揭露的字母，不計入速度和準確率。
- 打開「顯示原文（照著打）」，單字和例句模式會變回照著打的抄寫練習；聽寫模式一律不顯示原文。
- 詞的來源可以選：最近學過、錯詞本、收藏、學習路線。跟讀模式固定使用「發音練習」清單。
- **有造句的字想練聽音或拼寫**，就在這裡練。

## 8. 資料儲存與備份

- **所有學習資料只存在這台裝置的瀏覽器裡**，包括進度、指定詞、認識的詞、自訂單字、造句、自訂搭配、發音練習清單和設定。手機和電腦之間不會同步。
- 「我的 → 匯出備份」會產生一個 JSON 檔，自訂單字的插圖也會包在裡面；到另一台裝置「匯入備份」即可。
- 清除瀏覽器資料會把學習資料一起刪掉，請定期匯出備份。
- 網站本身（程式碼、詞庫、插圖、錄音）在 GitHub `leai7/word-atlas`，推送到 main 後會自動部署到 `https://leai7.github.io/word-atlas/`。

## 9. 已知限制（暫不處理）

- **雅思例句的發音**：7,298 句中只有 1,011 句有真人錄音，其他靠裝置內建朗讀。裝置沒有英文語音時（例如手機語言設成中文）會沒有聲音。
- **造句不會自動檢查文法。**
- **跨裝置同步**：需要另外接雲端服務，目前沒有。
