# 学习模型 / Learning model

## 每日旅程

- **复习**：所有到期的词（FSRS 计算的 `due` 已过）。
- **新词**：每天上限可设（默认 10），也可以按考试计划自动安排。名额里先放你指定的词（按指定顺序），不够再从学习路线中你的起点难度开始补上未学过的词；超出名额的指定词排到之后几天。旅程进行中指定新词时，会顶替旅程里还没见到的系统词。
- **认识的词**：系统推荐的词可以在「今日」页或「初次见面」卡片标记为认识，之后不再安排，并由下一个词补上；在单词页可以取消。
- **自订单词**：在「我的 → 自订单词」逐个新增词库里没有的词（单词、中文意思必填；词性、音标、例句、常用搭配、级别、话题、插图选填）。搭配可以直接从字典粘贴，每行一个。新增时可选择加入今天的新词（算在每日名额内）。自订单词不在学习路线和星图里，只通过指定或待学清单学习；发音用设备朗读；有插图且有例句才会出「看图补句」题。文字随学习进度保存，插图存在浏览器的 IndexedDB，导出备份时一并带上。
- **我的造句（chunks）**：在单词页「常用搭配」点「造句」，用该搭配写一句自己的英文句子（中文翻译选填）。系统自动找出句子里对应搭配的部分作为挖空，可手动修改（不规则变化如 give → gave 需要手动标）。新造句隔天开始复习，之后由 FSRS 排程，并入每日旅程、排在单词复习之后：显示你的句子并挖空搭配，提示搭配的中文，打出挖空的部分。修改句子不影响排程；删除造句会一并删除排程。
- **考试计划**：设置雅思考试日期和目标分数后，按常见的 CEFR 对应（≤5 分 B1、5.5–6.5 B2、7–8 C1、8.5 C2）算出从起点到目标级别还没学的词，平均分到考前（最后 3 天只复习）的每一天，每天最多 60 个。
- 顺序：先复习，再以 5 个为一组学新词：先「初见」认识 5 个词，再打乱顺序回忆这 5 个词。

## 题型

| 题型 | 适用 | 说明 |
| --- | --- | --- |
| 选义 | 新词、记忆弱 | 看英文选中文，干扰项词性相同 |
| 看图补句 | 新词、记忆弱 | 插画 + 挖空例句，选英文词，干扰项拼写相近 |
| 听音辨词 | 各阶段 | 只听发音选词 |
| 拼写 | 稳定度较高 | 看图和释义拼写，可以逐字母提示（提示后最多计 Hard） |

## 评分与 FSRS

每个词在一轮中只有**第一次作答**更新记忆（ts-fsrs，FSRS-6，默认目标记忆率 90%）：

- 答错 → Again
- 答对但慢、或用了提示 → Hard
- 答对 → Good；拼写又快又对 → Easy

答错的词会在几题之后换一种题型再练一次（最多两次），重试不再评分，也不计入正确率。

「已掌握」= FSRS 复习状态且记忆稳定度 ≥ 21 天。

## 打字练习

打字只训练输出，不改变记忆状态。WPM 按每 5 个正确字符计 1 词。

单词与例句练习默认不显示原文，只用「·」提示字母数：单词看图和释义拼写，例句看中文默写；打错的位置显示你打的字，不泄露答案。想不起来可以点「提示一个字母」（提示的字母不计入速度和准确率）。打开「显示原文」即回到照着打的抄写练习。听写与三种练习都只用每个词的第一句「日常」例句。
